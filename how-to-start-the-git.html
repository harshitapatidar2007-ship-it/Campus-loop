CampusLoop Developer Guide

How to Start & Run on Any PC

Complete step-by-step instructions to set up this project from GitHub on any new computer.

📂 GitHub Repository: harshitapatidar2007-ship-it/Campus-loop ↗
1
Prerequisites

Ensure you have Node.js and Git installed on the new computer:

  • Node.js (v18 or higher recommended): Download from nodejs.org
  • Git: Download from git-scm.com

Check in your terminal:

node -v
npm -v
git --version
2
Download / Clone the Repository

Open a terminal (PowerShell, Command Prompt, or Terminal) and run:

git clone https://github.com/harshitapatidar2007-ship-it/Campus-loop.git
cd Campus-loop

💡 Alternatively: On GitHub, click Code → Download ZIP, extract the folder, and open terminal inside it.

3
Install Dependencies (Generates node_modules)

Run the install command to download all project dependencies:

npm install

⚙️ This reads package.json and automatically installs clean, OS-compatible packages into a freshly generated node_modules folder.

4
Set Up Environment Variables (Optional)

If connecting to Supabase or third-party APIs, copy the sample environment file:

cp .env.example .env.local # On Windows PowerShell: copy .env.example .env.local

Fill in your Supabase URL and Anon Key if you are using a live Supabase backend. (The app also includes a fully functional in-memory demo mode!).

5
Start the Development Server

Launch the Next.js development server:

npm run dev

Now open your browser and navigate to:

http://localhost:3000 ↗
❓ Why are .git, node_modules, and .next not copied?

When transferring code via Git or sharing a project, these three folders are never transferred manually:

Folder Why it is not in the repository How it is created on the new PC
.git Stores Git's internal local repository logs. Automatically created by git clone or git init.
node_modules Contains ~500MB of machine-specific binary packages. Automatically downloaded cleanly by running npm install.
.next Temporary local build and compiler cache. Automatically generated by npm run dev or npm run build.
